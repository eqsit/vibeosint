# Промпты VibeOSINT — модульная сборка

Этот каталог — источник текстовой части системного промпта, которую панель добавляет к КАЖДОМУ сообщению агента (execution contract, режим, session_id, вложения, запрет выдумок, фильтр мусора, живой отчёт).

## Как это работает

- `server/index.mjs` больше не хранит эти тексты: он импортирует `server/prompt_builder.mjs`.
- Сборщик читает все файлы вида `NN_*.md` из этого каталога (по возрастанию имени) и склеивает их без разделителей — заново на каждый запрос.
- Правки в этих файлах применяются к следующему сообщению — БЕЗ рестарта панели.
- Каталог можно переопределить переменной окружения `PANEL_PROMPTS_DIR`.

## Файлы (порядок задаётся префиксом NN)

| Файл | Содержимое |
|---|---|
| `00_header.md` | заголовок расследования, цель, история переписки |
| `10_mode.md` | префикс режима расследования |
| `20_execution_contract.md` | область и критерий завершения, проверка источников, инструменты |
| `30_proxy.md` | маршрутизация через прокси (только если задан `HERMES_PROXY`) |
| `40_session_id.md` | требование передавать session_id во все MCP-вызовы |
| `50_attachments.md` | блок прикреплённых изображений (только при вложениях) |
| `60_request.md` | строка запроса пользователя |
| `70_no_invention.md` | запрет на выдумки |
| `80_junk_filter.md` | фильтр мусора для отчёта |
| `90_live_report.md` | контракт живого отчёта (osint_report_*) |

Можно добавлять свои модули: любой файл `NN_имя.md` подхватится в порядке NN.

## Плейсхолдеры

`{{TITLE}}` — заголовок сессии · `{{GOAL}}` — текст запроса · `{{HISTORY}}` — история переписки ·
`{{SESSION_ID}}` — id сессии · `{{PROXY}}` — адрес прокси · `{{ATTACHMENTS}}` — список файлов вложений.

## Условия

- `{{#proxy}}A{{/proxy}}` — только если задан прокси
- `{{#attachments}}A{{/attachments}}` — только если есть вложения

Вложенные условия не поддерживаются.

## Проверка

```bash
# предпросмотр собранного промпта (ничего не трогает, просто печатает)
node /opt/vibeosint/server/prompt_preview.mjs

# тесты панели (включая проверку модулей)
node --test /opt/vibeosint/server/*.test.mjs

# статус модулей в проде (после рестарта панели)
curl -s http://127.0.0.1:3000/api/health | python3 -m json.tool
```

## Важно

- Тексты файлов — UTF-8, обычный Markdown; синтаксис условий не вкладывать.
- Если файл отсутствует — блок просто не попадёт в промпт (в логе панели будет предупреждение).
- `workspace/AGENTS.md` — отдельный файл Hermes (читается из рабочей директории агента), НЕ часть этой сборки.
