# VibeOSINT — документация

Основной актуальный README теперь ведётся **на русском языке**: **[README.md](README.md)**.

В репозитории два самостоятельных интерфейса:

- **Текущая веб-панель** — [`panel/`](panel/); возможности, установка, зависимости, безопасность, тесты, ограничения и план разработки описаны в [основном README](README.md).
- **Сохранённый legacy-плагин Obsidian** — `main.js`, `manifest.json`, `styles.css` в корне. Его подробная [русская инструкция](docs/obsidian/README_RU.md) и [English README](docs/obsidian/README.md) сохранены отдельно.

Документация плагина не описывает установку панели. Canvas/DEEP и хранение в vault из старого руководства нельзя считать возможностями текущей веб-панели. Ключи, аккаунты, Telegram-сессии и результаты расследований в публичную поставку не входят.
