# Gemini Canvas OSINT (Плагин для Obsidian)

[🇬🇧 Read in English](README.md)

**Gemini Canvas OSINT** — плагин для Obsidian, предназначенный для проведения визуальных OSINT-расследований прямо на холсте Obsidian Canvas. С помощью автономных AI-агентов и LLM плагин автоматически строит графы связей, цифровые следы, досье на объекты и деревья сущностей в реальном времени.

## Основные возможности

- **Интеграция с Obsidian Canvas**: Визуализирует результаты расследования в виде связанных карточек (нод) и направленных ребер прямо на активном холсте.
- **Иерархическая раскладка связей**: Автоматическое позиционирование карточек слева направо (Цель -> Категории -> Связи -> Доказательства), динамический расчет размеров под текст и предотвращение наложений.
- **Два режима работы**:
  - **Hermes ACP (Автономный агент)**: Интеграция с [Hermes Agent](https://hermes-agent.nousresearch.com) через протокол ACP (Agent Client Protocol). Агент автономно выполняет команды в терминале, веб-поиск, пишет скрипты на Python и верифицирует данные в открытых реестрах.
  - **Direct API (Прямой вызов LLM)**: Поддержка любых OpenAI-совместимых эндпоинтов, Google Gemini, OpenRouter и кастомных моделей через REST API.
- **Подсистема прокси и обхода блокировок**: Нативная маршрутизация сетевых запросов через SOCKS5H / HTTP прокси для надежного сбора данных в условиях геоблокировок и региональных фильтров.
- **Интерактивный чат в боковой панели**: Удобная панель управления расследованием, отображение шагов агента, вызываемых инструментов и потоковый вывод текста.
- **Умное обновление и дедупликация**: Автоматическое обновление существующих карточек при появлении новых фактов и удаление опровергнутых гипотез без дублирования.
- **Приватность и локальность**: Работает локально в вашем хранилище Obsidian. Без внешних трекеров и телеметрии.

## Подсистема прокси и маршрутизация сетевых запросов

Важнейшая часть практического OSINT — бесперебойный доступ к международным базам данных, реестрам, архивам и социальным сетям, многие из которых применяют геоблокировки (403 Forbidden, Region Block, Cloudflare Anti-Bot) или подвержены ограничениям интернет-провайдеров.

В плагине предусмотрена архитектура маршрутизации трафика:

1. **SOCKS5H с удаленным резолвом DNS**:
   - При работе через прокси используется протокол `socks5h://`, при котором DNS-запросы разрешаются на стороне прокси-сервера. Это исключает DNS-утечки (DNS leak), подмену ответов (DNS poisoning) и блокировки по доменным именам на уровне локального провайдера.
2. **Маршрутизация инструментов расследования**:
   - Любые поисковые скрипты и утилиты, запускаемые агентом (`curl`, Python-библиотеки `requests`/`aiohttp`/`urllib`, автоматизация браузера `browser_exec`), используют настроенный прокси-маршрут при обращении к заблокированным ресурсам.
3. **Изоляция локального IPC-моста (NO_PROXY)**:
   - Внутреннее взаимодействие между плагином Obsidian и агентом (ACP daemon) защищено директивой `NO_PROXY=127.0.0.1,localhost`. Это гарантирует, что локальный трафик обмена данными никогда не направляется во внешний прокси и не вызывает задержек или сбоев.

### Настройка прокси

Вы можете использовать любой локальный клиент (например, SOCKS5/HTTP на `127.0.0.1:2080`, Tor на `127.0.0.1:9050`, Xray, Nekoray или корпоративный прокси-сервер). Для этого достаточно задать стандартные переменные окружения (`ALL_PROXY`, `HTTPS_PROXY`) или настроить параметры сети в профиле агента.

## Установка

### Ручная установка

1. Скачайте или клонируйте этот репозиторий.
2. Скопируйте файлы плагина в папку вашего хранилища:
   `<Хранилище>/.obsidian/plugins/gemini-canvas-osint/`
   - `manifest.json`
   - `main.js`
   - `styles.css`
3. Перезагрузите Obsidian (`Ctrl+R` или перезапуск приложения).
4. Перейдите в **Настройки -> Сторонние плагины**, найдите **Gemini Canvas OSINT** и включите его.

---

## Настройка

Откройте **Настройки -> Gemini Canvas OSINT**:

- **Режим движка (Engine Mode)**:
  - `Hermes ACP` — полнофункциональный агент с доступом к инструментам и терминалу.
  - `Direct API` — прямой опрос языковой модели через REST API.
- **Настройки Hermes ACP**:
  - Требуется установленный и доступный в системе Hermes Agent (`hermes`).
  - Укажите идентификатор модели (например, `agy/gemini-3.8-flash-high`, `gemini-2.0-flash`).
- **Настройки Direct API**:
  - Укажите `API Base URL` (например, `https://api.openai.com/v1` или OpenRouter).
  - Введите `API Key`.
  - Выберите целевую модель.

---

## Использование

1. Откройте существующий файл `.canvas` или создайте новый в Obsidian.
2. Нажмите на иконку прицела на левой панели (ленте) или откройте боковую панель **OSINT Canvas Agent**.
3. Введите объект расследования (номер телефона, никнейм, домен, организацию, ИНН или ФИО).
4. Наблюдайте, как агент собирает факты и формирует граф расследования на холсте.
